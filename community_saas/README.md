# Community SaaS Theme

Mobile-first Redmine theme for positioning ModuleX as a community service portal.

## Install

1. Copy `community_saas` into Redmine `public/themes`.
2. Set Redmine theme to `community_saas`.
3. Optional homepage: add `view_customize/community_home.js` to View Customize as JavaScript for path `^/$`.

The theme is designed to avoid Redmine core changes so it can be rolled back by switching the active theme.
