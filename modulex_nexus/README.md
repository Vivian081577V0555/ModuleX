# ModuleX Nexus

A self-contained Redmine 5 theme designed for operational clarity on desktop displays.

## Install

1. Copy `modulex_nexus` to the Redmine `public/themes` directory (or the host directory mounted there).
2. Restart Redmine.
3. Select **ModuleX Nexus** in Administration > Settings > Display.

The homepage command center is injected by `javascripts/theme.js`. No external fonts, images, or network resources are required.

At desktop widths of 1280px or above and heights of 800px or above, the homepage fits within one viewport and suppresses the page scrollbar. Other pages retain normal scrolling.
