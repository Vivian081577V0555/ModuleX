# Redmine Community Booking

Project-level facility booking for Redmine 5.1.

## Features

- Manage facilities per project.
- Set hourly capacity, opening hour, and closing hour.
- Display per-hour booked quantity and remaining capacity.
- Users book one-hour slots.
- Users can cancel their own bookings; managers can cancel any booking.

## Example

Create a facility named `健身腳踏車`, set capacity to `5`, opening hour to `8`, and closing hour to `22`.
Each one-hour slot can then accept up to five bookings and shows the remaining amount on the calendar page.
