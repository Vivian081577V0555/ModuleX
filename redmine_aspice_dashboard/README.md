# ASPICE Live Dashboard

Provides the `{{aspice_dashboard}}` Wiki macro. Every page request calculates
traceability counts, end-to-end coverage, verification verdicts, and the Golden
Path matrix directly from Redmine issues and custom fields. Metabase is not
required.

Install the plugin in Redmine's `plugins` directory, restart Redmine, and place
`{{aspice_dashboard}}` on the ASPICE dashboard Wiki page.
